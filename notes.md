ENGINEERING - TOURISM INDECES

Tourism index is constructed upon nights of stay (tourism pressure), number of beds (tourism capacity), number of str (residential displacement).


PRE ANALYSIS
1. Visualise data -> MANDATORY
2. Descriptive statistics
3. Unit-root (check whether the introduction of the lagged outcome variable is appropriate)


MODELS
1. Benchmark OLS FE model with entity fixed effects -> biased because strong persistence of outcome variable. However, if the latter is included, due to few time points, Nickel bias is present.

2. Level System-GMM model with entity fixed effects -> captures long-run trends. We can perform different sensitivity tests.

3. Growth System-GMM model with entity fixed effects -> captures short-run trends and shows the importance of population. Therefore, tourism indices can be interacted.

4. Repeat the same with data on province capitals -> good sensitivity test
